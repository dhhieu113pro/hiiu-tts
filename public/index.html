Generate speech

POST /v1/audio/speech

Send an OpenAI-compatible speech request. The response body is the generated audio, not JSON.

curl -X POST https://hiiu-tts.netlify.app/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Ngọc Huyền (mới)",
    "input": "Xin chào Việt Nam!",
    "speed": 1.0,
    "response_format": "wav"
  }' \
  --output speech.wav
inputstring, required

Text to synthesize. Maximum 500 characters in this console to prevent timeout.

modelstring

Any of the 20 model names returned by GET /v1/tts/models (e.g. Ban Mai).

speednumber

Playback speed from 0.25 to 4.0. Default is 1.0.

response_formatstring

wav or headerless 16-bit mono pcm.

Long text is split into phrase-sized chunks. The API inserts a short pause between chunks and a final tail so high-speed output does not end abruptly.

Response formats

Status 200 with raw binary audio.

Install another model

Vercel Functions have no persistent model directory. Choose the voice at build time, then deploy a new immutable function bundle.

  1. List catalog voices
    curl https://nghitts.app/api/models
  2. Download a voice locally
    NGHITTS_VOICE="Ngọc Huyền (mới)" npm run assets
  3. Build or deploy with that voice
    NGHITTS_VOICE="Ngọc Huyền (mới)" npx vercel --prod

One deployment currently contains one voice. The downloaded files are stored as models/voice.onnx and models/voice.onnx.json.
